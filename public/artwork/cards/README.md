# Card artwork

- `shuffle-hands.png`: genuine printed illustration extracted directly from Mattel’s Classic/Shuffle instructions. Its luminance filter is applied only by the shared renderer.
- `color-roulette.png`: source-informed, AI-cleaned and recolored derivative from Mattel’s No Mercy instructions. Four complete faces retain opaque yellow, blue, green and coral fills and transparent surroundings. It is not an unmodified original print.

Each asset retains embedded provenance and an adjacent `.origin.txt` history. Exact cleanup/recolor prompts are included. No generation or visual asset edits occurred during production integration. The standalone design lab was retired after these faces moved into `UnoCard`.
