# Quality bar

Keep exact user-approved Swiss card identity at production sizes: solid fields, upright Space Grotesk700, mirrored aligned corner indices, underlined6/9, shared approved action geometry and complete sourced/derivative raster artwork. Nordic retains the same geometry with dark fields and colored ink. Default is Swiss, exactly one alternate persists locally; both full setting labels must fit desktop and phone. Keep existing arena/hand sizing, cropping, gestures, turns and motion. No lab ring/finish/table/movement controls, dead alternate paint rules, new dependencies or misleading original-art claims. No manual multiplayer required. Technical acceptance: production build, lint, strict types, engine/card/prefs assertions, audio and automated socket checks. Visual acceptance is scoped to card integration/settings across captured desktop and supported phone landscape, with portrait orientation guard preserved.
